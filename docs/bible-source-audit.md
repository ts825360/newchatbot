# 오늘의 묵상 출처 확인

2026-11-27 기준. 앱은 한국 날짜를 기준으로 서버에 고정된 10개 구절을 순환 선택한다. 선택 시 AI나 외부 성경 API를 호출하지 않는다. 교회가 추가로 승인한 판본 목록은 확인하지 못했으므로 기존 번역본을 다른 번역으로 대체하지 않았다.

- 판본: 성경전서 개역한글판(KRV), 대한성서공회, 1961년. [대한성서공회의 판본 목록](https://www.bskorea.or.kr/bbs/board.php?bo_table=copyright_faq&wr_id=3) 및 [YouVersion 판본 정보](https://www.bible.com/ko/versions/88).
- 현행 서버 데이터 10개를 연결된 구절 페이지에서 장절과 본문까지 대조했다. 불일치가 없었으며 구절, 번역본 표기, 선정 방식은 그대로 둔다.
- [대한성서공회 개역한글 이용 FAQ](https://www.bskorea.or.kr/bbs/board.php?bo_table=copyright_faq&wr_id=5)는 해당 판본의 저작재산권 보호기간이 경과해 저작권료 없이 사용할 수 있다고 안내한다. 동시에 성명표시와 동일성유지를 요구한다. 본문과 제목을 변경하지 않고 기존 장절·번역본·발행처·원문 링크를 유지한다. 이 확인을 개역개정 등 다른 번역이나 YouVersion 매체·데이터 사용 허락으로 확대하지 않는다.
