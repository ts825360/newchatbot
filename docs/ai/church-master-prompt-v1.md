# 선화침례교회 범용 AI — Master Prompt v1 (초안)

## 목표
특정 API 모델에 종속되지 않는 판단 체계. 행사비서는 첫 적용 서비스이며 향후 자체 GPU 모델로 이식할 때도 정책과 판단 기준을 유지한다. 동일 성능은 보장하지 않는다.

## 구성
- lib/server/church-core-prompt.ts: 범용 정체성, 의도, 맥락, 판단, 정보 활용, 실행, 전달, 검증.
- lib/server/chat-advisor-prompt.ts: 행사 업무, 교회 용어, 배정 정책, 권한·근거 및 현재 출력 계약.
- lib/server/chat.ts: 현재 실행 경로의 문맥과 도구 지침. 설문 도구 지침만 수정했다.
- 서버 권한·개인정보 검사, 승인, 실제 도구 계약은 프롬프트보다 우선한다.

## 정적 비교 (API 미호출)
| 요청 | 현재 구조의 위험 | 목표 행동 | 남은 시스템 과제 |
|---|---|---|---|
| 지금 우리가 어디까지 한 거야? | 최근 대화만 보고 행사 전체로 단정 | 참조 범위 판단, 확인된 상태와 다음 행동 | 작업 상태·공동 자료 조회 및 문맥 확장 |
| 수련회 설문을 제작해줘 | 정형 분기 또는 기본 양식으로 목적 누락 | 목적과 후속 배정에 맞는 검토 초안 | 정규식 우회 경로와 도구의 실제 분기 지원 확인 |
| 숙소를 바꾸자 | 숙소만 변경 | 일정·이동·비용·수용 조건 재검토 | 관련 도구 연결 |
| 가상 수련회 준비 10개 | 온라인 행사로 오해, rows 초과 | 가상 여부와 진행 방식 분리, 번호 10개 | 적응형 출력 계약 |
| 지난 행사처럼 해줘 | 과거 조건을 현재 사실로 오해 | 과거 기록 확인 후 차이 비교 | 행사 기록/RAG |
| 종합 기록서 작성 | 4행 요약을 완성 문서로 오인 | 계획/실제/미확인 분리, 표준 문서 | 문서 생성 도구 |
| 주변 활동 추천 | 1~3곳 검색 경로, 발견 다양성 제한 | 조건 보존, 다양한 발견과 검증 | 검색·후보 구조 확장 |
| 고마워 | 불필요한 업무 제안 | 자연스러운 짧은 응답 | 없음 |

## 검증 및 운영
자동 유료 평가는 사용자 요청 전 실행하지 않는다. 사용자가 실제 채팅을 평가하고 Codex는 전달된 맥락·프롬프트·도구·파서·로그를 조사한다. 모델 내부 사고를 관측했다고 주장하지 않는다. ChatGPT는 예상 행동과 목표 행동의 차이에서 범용 원칙을 추출한다. 개인 대화 원문이나 개인 프로필을 교회 공통 프롬프트에 저장하지 않는다.

## 미완료
정적 검토는 전체 저장소 감사가 아니다. 별도 검색 경로, 로컬 분기, 도구 한도, 고정 출력 스키마, 작업 상태 저장 및 실제 모델 성능은 추가 검토가 필요하다. TypeScript 및 회귀 테스트는 Codex의 무과금 검증 전까지 미확인이다.
