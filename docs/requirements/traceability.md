# 행사비서 요구사항 추적

기준: [사용자가 제공한 원문](brief-v2.md), 기존 [AI 개선 로드맵](../assistant-improvement-roadmap.md), Google 외부 서비스 연결 시안(2026-11-27). 원문 번호 `G`는 범용 지침, `P`는 프로젝트 지침, `T`는 수행 및 누락 방지 지침을 뜻한다. 같은 구현과 검수 기준을 공유하는 원문 표현은 한 ID로 묶었다. 아래 상태는 기능 구현뿐 아니라 실제 검증 수준도 구분한다.

상태: `미착수`, `진행 중`, `부분 구현`, `구현 완료`, `검증 완료`, `작업 차단`. 이 문서의 `검증 완료`는 해당 행의 범위에만 적용하며 실제 서비스 검증이 필요한 다른 행을 완료시키지 않는다. `—`는 아직 확인하지 않은 결과나 해당 없는 의존성을 표시한다.

| EXT-06 · 외부 5 | 연결된 서비스는 기존 행사 관리 기능으로 동작하고, 읽기와 변경의 권한 및 승인 정책을 유지한다. | 부분 구현 | Google 일정 전송·설문 미리보기·승인 생성 | 기존 기능이 동작하나 실 계정 API 검증과 범용 오케스트레이터는 별도. |
| EXT-07 · 외부 5·P14 | 외부 서비스 결과를 허용 범위 내에서 복합 행사 업무와 연결한다. | 미착수 | EXT-06, ORC-01/02/03/06 | 실 서비스 검증 후 읽기 전용 사례부터 추가. |
| EXT-08 · 외부 6·T4 | 실제 계정으로 OAuth와 Calendar/Forms의 실제 전송·조회·미게시 생성을 검증하고 API별 결과를 남긴다. | 작업 차단 | 승인된 검증용 OAuth 계정과 테스트 캘린더·설문 | 실제 Google 자격 증명으로 실행하지 않음. 모의 응답과 인증 확인을 서비스 정상 판정으로 간주하지 않는다. |

## 단계 및 재개 지점

1. **현재 제출:** EXT-01~05의 화면·진단, 원문과 추적 문서. OAuth 권한/DB 스키마/기존 기능은 유지한다. 오프라인 전체 회귀·브라우저 결과와 실제 Google 미검증(EXT-08)을 분리한다.
2. **다음 독립 작업:** ORC-01/02/06. 타임테이블과 공동 일정의 시간 충돌 및 이동 전후 여유를 비식별·읽기 전용으로 조회하고 제안까지 연결한다. 변경 전후와 계정·행사방 전환을 회귀 검증한다.
3. **후속:** ORC-03~08. 참가 인원·장소 변경의 영향과 여러 제안의 승인/부분 실패 복구를 작은 작업 단위로 검증한 뒤 종합 평가한다. 실제 Google 계정 테스트는 승인된 시험 환경에서만 진행한다.

### 2026-11-27 진단 단계 검증

- Vitest 전체: 934개 통과, 실제 OpenAI 호출 1개 건너뜀. Google 진단 API의 응답/권한 분기는 모의 OAuth 클라이언트로 검증했다.
- 프로덕션 Docker 빌드와 Compose 설정 유효성 검사를 통과했다. 기존 운영 DB가 없는 별도 컨테이너의 브라우저에서 미설정 상태(1185×920, 390×844), 미설정 시 비활성 버튼, 관리자 필드명, 연결 테스트의 모의 결과를 확인했다.
- 실제 로컬 앱에 OAuth 설정이 전달되었는지 여부만 확인했다. 지금은 필수 항목이 모두 미설정이다. Google 자격 증명을 입력하거나 실제 OAuth, Calendar 전송, Forms 조회/생성 API를 호출하지 않았다.
